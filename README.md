> **Stop wasting connects on the wrong jobs.**  
> A free Chrome Extension that scores every Upwork job in real-time based on YOUR skills and profile.

Every freelancer has felt this. Upwork's "best match" sort isn't actually *your* best match. You scroll, skim, second-guess, and burn connects on jobs you were never going to win.

## ⚡ How It Works

Three steps. Two minutes. No signup. No account. No tracking.

![How It Works](assets/Upwork%20highlighter_page-0003.jpg)

**Step 1 —** Install the Chrome extension (just 2 files)  
**Step 2 —** Enter your skills, categories, JSS score, and red-flag keywords — once  
**Step 3 —** Open Upwork jobs page — every job is auto-scored and color-coded, live

## ✨ Features

![Features](assets/Upwork%20highlighter_page-0004.jpg)

| Badge | Meaning | Action |
|-------|---------|--------|
| 🟢 **Best Match** | Score 55+ — skills aligned, good budget | Apply now |
| 🟡 **Possible Match** | Score 35–54 — partial fit | Read before applying |
| 🔴 **Not Best Match** | Score below 35 — wrong stack or red flag | Save your connects |

**Additional features:**
- 🎨 Whole job card glows by score — scan the page in 5 seconds
- 🇺🇸 USA client location highlighted in green
- ⚙️ Edit your profile anytime — no reload needed

## 🧠 Scoring Engine

![Scoring Engine](assets/Upwork%20highlighter_page-0005.jpg)

A simple, transparent points system:

| Signal | Points |
|--------|--------|
| Skill match (per keyword) | up to **+40** |
| Strong category match | up to **+20** |
| JSS 100% + Top Rated | **+15** |
| Low competition (few proposals) | **+10** |
| Red-flag keyword detected | **−30** |
| Low budget job | **−15** |

> **Hover any badge** to see the exact score, matched skills, and reason.

## 🚀 Installation — 2 Minutes

![Install Guide](assets/Upwork%20highlighter_page-0007.jpg)

```bash
# 1. Download or clone this repo
git clone https://github.com/numan/upwork-best-match-highlighter

# Folder will contain:
manifest.json
content.js
```

**Manual install steps:**

1. Download `manifest.json` + `content.js`
2. Open `chrome://extensions` in your browser
3. Toggle **Developer Mode** ON (top right)
4. Click **Load Unpacked** → select the folder
5. Visit Upwork jobs page → watch the magic ✦

## ⚙️ Setup Panel Fields

When you first install, a setup panel opens automatically:

| Field | Description | Example |
|-------|-------------|---------|
| **Your Skills** | Tech keywords matched against job descriptions | `php, laravel, react, vue, wordpress` |
| **Strong Categories** | Job types where you have most experience | `full stack, web development, api` |
| **Red Flags** | Keywords that mark a job as Not Best Match | `java developer, data entry, devops` |
| **JSS %** | Your current Job Success Score on Upwork | `100` |
| **Total Earnings** | Your lifetime Upwork earnings in USD | `10000` |
| **Top Rated** | Check if you are Top Rated or Top Rated Plus | ✅ |
